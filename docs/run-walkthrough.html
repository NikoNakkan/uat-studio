    The 11 stages

    Who runs each step, and with what

    Before every agent action: scripts/guard_hook.py checks the call against config/guardrails.yaml (the Guardrails page): only the allowed sites, no blocked tools, never .env, and it asks you before clicking anything with delete, remove, send, pay. In this run it refused the planner's browser_evaluate twice.
    Loops

    Where the flow goes back

    Check steps in the live app → Clarify the cases

    Steps that do not match the real app (a button with another name, a missing page) go back to the clarifier as questions for you, then the plan is rewritten and checked again. At most 2 rounds (max_planner_rounds).

    This run: no mismatches, so no round. On the run page, Clarify shows as running again with "Round 2, from the live app check" while it happens.

    Check the tests → Write the tests

    A test the check rejects goes back to the generator with the reasons. At most 2 attempts per case (max_generate_attempts); a case still rejected after that is reported at sign-off.

    This run: TC-15 went back once. The check said "the check does not contain 'Paracetamol 6 on hand'"; the second version was accepted and passed 3 repeat runs.
